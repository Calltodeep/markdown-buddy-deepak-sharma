# Assignment Reflection: Markdown Buddy

## 1. Strengths and Weaknesses of AI-Assisted Documentation Workflows
* **Strengths:** Generative AI models excel at rapidly generating clean Markdown skeletons, suggesting professional section headers, and establishing consistent documentation formatting across projects[cite: 1, 2, 3]. It significantly reduces the initial friction of structuring a repository[cite: 1].
* **Weaknesses:** AI tools can occasionally introduce syntax inconsistencies or structure explanations that do not match custom local datasets. Manual validation and domain expertise remain essential to catch these discrepancies.

## 2. Ethical Practices and Attribution
Maintaining academic integrity and professional transparency requires explicit disclosure of all AI tool interactions. Throughout this assignment, I adhered strictly to course rules by providing an explicit AI Assistance Declaration, recording every seed and refinement prompt in an appendix, and performing rigorous manual verification before finalizing my submissions[cite: 2].

## 3. Value of Iterative AI Prompting
Moving from broad seed prompts to targeted refinement prompts drastically improved output quality[cite: 2, 3]. Iterative prompting allows creators to hone the tone, eliminate redundancy, and ensure that technical documentation meets professional GitHub best practice standards[cite: 1, 3].
